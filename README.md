# PKU Gamping Mobile

Aplikasi mobile pasien RS PKU Muhammadiyah Gamping.

## Teknologi
- Flutter (Dart) — frontend
- CodeIgniter — backend/API

## Status
Dalam pengembangan sebagai project magang.

## Fitur
- Autentikasi pasien (Lihat detail: [README_AUTH_API.md](README_AUTH_API.md))
- Pendaftaran online
- Informasi antrean
- Jadwal dokter
- Profil dan riwayat pasien

## Dokumentasi API & Modul
- [Dokumentasi API Autentikasi & Registrasi (README_AUTH_API.md)](README_AUTH_API.md) — Rangkuman lengkap alur, endpoint, file, dan kodingan untuk fitur Splash, Login, Register, Lupa Kata Sandi, dan OTP.
